# 혼잡도 추정 방법론 (Phase 1: 체류인원 계산 + LOS)

## 목적
Apex의 핵심 차별화 기능인 **접근성 × 혼잡도 결합 판정**을 위해, 역 내부 구역별
혼잡을 수치로 추정한다. 사용자 계획의 2단계 중 **(1) 계산** 단계를 실데이터로 구현했다.
(2) 예측·환승·비교는 Phase 2+로 이월.

## 이론적 근거

### Little's Law (Little, 1961)
> 대기 시스템의 평균 체류 인원 **L = λ · W**
> (λ = 평균 도착률, W = 평균 체류시간)

역 구역을 하나의 대기 시스템으로 보면, 시간당 유입 인원(승차·하차·환승)에 그 구역에서의
평균 체류시간을 곱해 **평균 체류 인원**을 추정할 수 있다. 승하차 데이터가 '시간당 인원'
이므로 λ 로 직접 쓰고, W(분)를 시간으로 환산해 곱한다.

### 구역 구분 (사용자 정의)
- **비유료구역**: 개찰구 밖 — 대합실, 게이트 앞 → 면적 = `대합실면적`
- **개찰구**: 경계 측정점
- **유료구역**: 개찰구 안 — 승강장, 환승통로 → 면적 = `승강장면적`
- 환승객은 개찰구를 통과하지 않으므로 별도 합산 필요(왕십리·동대문역사문화공원 등)

## 계산식 (구현: `src/occupancy.py`)

| 구역 | 체류인원 공식 | 근거 |
|------|---------------|------|
| 비유료(대합실) | 승차객×게이트대기 + 하차객×출구이동 | Little's Law |
| 유료(승강장) | 승차객×열차대기 + 하차객×게이트이동 + (환승객×통로통과) | Little's Law |
| 환승난이도 | 환승인원 ÷ 통로면적 × 통과시간 (= 밀도) | 국토부 LOS |

- **열차대기시간 = 배차간격 / 2** (도착이 균등하다는 가정 하 평균 대기)
- 환승항은 **Phase 1에서 0 처리**(환승 데이터 부재). 함수 인터페이스(`transfer` 인자)는 마련.

## LOS 등급 (구현: `src/los.py`)
1인당 점유면적(㎡/명) = 면적 / 체류인원 → Fruin 보행 서비스수준(1971) 기준 A~F.

| 등급 | ㎡/명 (하한) | 의미 |
|------|-------------|------|
| A | ≥ 3.24 | 자유 통행 |
| B | ≥ 2.32 | |
| C | ≥ 1.39 | |
| D | ≥ 0.93 | 국토부: 승강장·계단 허용 하한 |
| E | ≥ 0.46 | 국토부: 환승통로 허용 하한 |
| F | < 0.46 | 정체 |

## 한계
- 시간 해상도는 승하차의 1시간 단위(혼잡도는 30분이나 승하차에 맞춤).
- 체류시간 가정에 결과가 선형 비례 → 파라미터 민감도 분석 권장(Phase 2).
- 면적 미매칭 역(당고개 등)은 LOS 계산에서 제외.

### ⚠️ 핵심 발견: 절대 LOS 등급 포화 (전부 A)
- 실행 결과 **모든 역·시간대의 승강장/대합실 LOS가 A**로 나온다(강남 피크 포함).
- 원인: 사용자 공식의 `열차대기 = 배차간격/2`는 **시간당 평균 체류인원**(사우투스 파형의 평균)을
  산출하는데, Fruin LOS는 **순간/설계 밀도** 기준이라 시간평균을 그대로 넣으면 밀도가 낮게 나온다.
  예) 강남 평일 피크 승강장 평균 체류 ≈ 608명 / 2,374㎡ = 0.26명/㎡ → 3.9㎡/명 → A.
- 따라서 **혼잡 신호는 등급이 아니라 상대적 밀도·체류량에 존재**한다(강남 608 vs 왕십리 96).
- 개선안(Phase 2, 사용자 승인 필요):
  1. **순간 첨두 모형**: 열차 도착 직전 승강장 누적 ≈ 승차율 × 배차간격(= 파형의 최댓값, 평균의 2배).
  2. **데이터 기반 4단계화**: 팀 결정(여유/보통/주의/혼잡)에 맞춰 밀도 분위수로 등급 재정의.
  3. **OA-12928 열차혼잡 %로 캘리브레이션**: 실제 열차 혼잡도(정원 대비)를 정답 라벨로 스케일 보정.

## 혼잡도 % (백분위) 정의
혼잡도 % = 그 밀도가 **평일 전 역·시간대 승강장 밀도 분포에서 차지하는 백분위수**.
4단계 경계(p50/p80/p95)가 곧 50/80/95%라 등급과 완전히 일관. 근거 분포 = `los_summary_byday`의 월~금.

## 프로필별 혼잡 기준 (일반 vs 휠체어)
같은 물리적 밀도라도 휠체어 이용자는 더 붐빈다고 느끼고 실제 이동이 더 제약됨. 근거:
- **ADA/UFAS 휠체어 정지 점유면적 = 0.76×1.22m ≈ 0.93㎡** — 일반 보행자 개인공간(약 0.3–0.5㎡)의 **약 2배**
- 연구: 군중에 휠체어 혼입 시 **병목 통과 유량 ~15% 감소**(휠체어 수에 비례). 휠체어는 혼잡에 더 취약
→ **휠체어 프로필 = 더 보수적(낮은 임계)·더 세분화(6단계)**
- 일반: 4단계, 백분위 밴드 [50/80/95]
- 휠체어: 6단계(여유/보통/주의/혼잡/심각/위험), 밴드 [30/50/70/85/95] — 같은 %라도 더 이른 단계
- ⚠️ 정확한 밴드 수치는 위 연구가 뒷받침하는 '방향'(더 보수적)에 근거한 **설계값**(연구가 백분위 컷을 직접 주진 않음). 향후 **개인별 임계 설정**으로 확장 예정.
- 참고: "평소보다 붐빔" 배지의 1.6배 임계는 표준이 아닌 **임의 휴리스틱**(추후 프로필/개인 설정으로 대체 권장).
